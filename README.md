  # TrustSealed

  An independent public registry of signed ownership certificates for websites,
  social accounts and GitHub projects.

  When someone clones your site or impersonates your account, a TrustSealed seal
  lets anyone check who the real owner is, and since when.

  - **Prove it:** owners prove control with a DNS record, a file or a post. No
  paperwork.
  - **Sign it:** every seal is an Ed25519-signed certificate with a serial
  number.
  - **Keep checking:** proofs are rechecked daily; a seal lapses if its proof
  disappears.
  - **Log it in public:** every issue and lapse goes into an append-only log,
  timestamped daily with OpenTimestamps.

  **Check any site or account:** [trustsealed.com](https://trustsealed.com)
